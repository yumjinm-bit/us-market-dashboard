● 데이터 확인 중
임의 시세값은 표시하지 않습니다. VOO·QQQM·SCHD·환율은 GitHub Actions가 서버에서 시장 데이터를 받아 5분 간격을 목표로 갱신하며, 카드의 원 시세 시각이 15분을 넘으면 경고합니다. 데이터 수집이 실패하거나 오래되면 숫자 대신 경고를 표시합니다.
15분 이내를 목표로 하지만 GitHub 예약 실행 자체가 지연될 수 있어 절대 보장은 아닙니다. Yahoo Finance chart endpoint는 비공식 시장데이터 피드이며 종목/시장에 따라 지연될 수 있습니다. VIX는 공개 원천 자체가 약 15분 지연될 수 있어 별도로 표시합니다. 일일 등락은 직전 완료 거래일 종가와 비교하고, 연초 대비(YTD)는 전년도 마지막 거래일 종가 대비 가격 변화로 계산합니다. 주문 직전에는 증권사 호가창과 대조하세요.

① 가짜값 금지

수집 실패 시 이전에 임의로 만든 숫자를 대신 보여주지 않습니다. 값이 없으면 “데이터 없음”으로 표시합니다.

② 시세 시각·기준 공개

페이지를 연 시각이 아니라 원 데이터 시장 시각을 표시합니다. 일일 등락은 직전 완료 거래일 종가, YTD는 전년도 마지막 거래일 종가를 기준으로 계산합니다.

③ 공시 지표는 기준일 표시

PER·Yield·순보수는 시세와 별도로 Yahoo Finance ETF 요약 페이지에서 자동 갱신하며, 마지막 성공 수집 시각과 출처를 표시합니다. 수집 실패 시 임의값을 만들지 않습니다.
